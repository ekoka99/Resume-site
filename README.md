# Elio Koka - Robotics Systems Portfolio

Personal portfolio for Elio Koka, a senior hardware/software integration engineer focused on humanoids, autonomous
systems, manufacturing automation, diagnostics, and scalable validation.

## Positioning

The site highlights the work required to turn complex robotics prototypes into reliable products:

- Cross-domain hardware/software bring-up
- Manufacturing execution and production test systems
- HIL, end-of-line validation, and diagnostic pipelines
- CAN, firmware, onboard compute, sensing, actuation, and power
- Technical ownership from ambiguous problem framing through production readiness

## Development

```bash
yarn install --frozen-lockfile
yarn dev
```

The site is statically exported under `/Resume-site` for GitHub Pages.
